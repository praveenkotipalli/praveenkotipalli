# 👋 About Me

> ### **"What if this could be better?"**
>
> *That's the question behind every product I build.*

I'm driven by curiosity and a passion for solving real-world problems through technology.

What if this application could be smarter? What if this workflow could be faster? What if AI could remove repetitive tasks and help people accomplish more? Those questions inspire every project I work on.

I enjoy transforming complex ideas into intuitive, scalable products by combining thoughtful user experiences with clean engineering. My playground is the full stack—from crafting responsive interfaces with **React**, **Next.js**, and **TypeScript** to building robust backends, designing scalable APIs, and integrating modern AI models.

Currently, I'm focused on building **Orbit**—a platform that helps developers discover hackathons, tech events, conferences, jobs, and opportunities in one place. Alongside that, I'm exploring AI-powered tools that make developers more productive, including resume analysis, job matching, and intelligent automation.
